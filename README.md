## 📂 Featured Projects

<td width="50%" valign="top">

### ✋ SignScribe — ASL Detector
Real-time American Sign Language alphabet recognition. Instead of feeding raw pixels to a CNN, it extracts 21 3D hand landmarks via MediaPipe and classifies them with a Random Forest model — faster and more accurate than image-based approaches, with prediction smoothing to stop character spam. 95%+ accuracy on the ASL alphabet.

`Python` `MediaPipe` `scikit-learn (Random Forest)` `OpenCV`

**[→ View Repo](https://github.com/darshild078/SignScribe-ASL-Detector)**

</td>
<td width="50%" valign="top">

### 🐦 Switter
A Twitter-style social platform on the MERN stack. Email/password + Google OAuth login with JWT sessions, editable profiles with cloud-hosted profile/cover images, follow/unfollow, and a full post & feed system.

`React 18` `Node.js` `Express.js` `MongoDB`

**[→ View Repo](https://github.com/darshild078/SocialMediaApp-MERN-Stack)**

</td>

### 📧 Email Spam Classifier
An AI-powered spam detector for email/SMS — Multinomial Naive Bayes tuned via hyperparameter search, TF-IDF vectorization plus hand-built spam-specific features, NLTK preprocessing (stemming, stopword filtering, URL/phone preservation), wrapped in a threaded Tkinter GUI.

`Python` `scikit-learn` `NLTK` `Tkinter`

**[→ View Repo](https://github.com/darshild078/Email-classifier-gui)**

</td>
<td width="50%" valign="top">

### 💰 CogniFin AI
An enterprise-grade RAG platform for analyzing Indian financial disclosures — SEBI DRHP/RHP filings, BSE/NSE annual reports, and quarterly earnings. Hybrid dense-sparse retrieval (`bge-base-en-v1.5` + BM25) with a cross-encoder reranker, grounded generation via Gemini 2.0 Flash with cited sources and confidence scores. Frontend has an in-app PDF viewer that auto-jumps to the cited page.

`FastAPI` `PyTorch / HuggingFace` `FAISS` `MongoDB` · `React 19` `Vite`

**[→ Backend](https://github.com/darshild078/cognifin_backend)** · **[→ Frontend](https://github.com/darshild078/cognifin_frontend)**

</td>
</tr>

### 🧪 Model Regression Detection System <img src="https://img.shields.io/badge/status-in%20development-orange?style=flat-square" />
A CI/CD-style quality gate for LLM-powered features — evaluates candidate prompts/models against a versioned golden dataset and an approved production baseline, and blocks regressions before they ship. SHA-256 prompt fingerprinting (content + behavior hashes) and a version registry are live; more evaluation coverage is in progress.

`Python` `CLI Tooling` `LLM Evaluation`

**[→ View Repo](https://github.com/darshild078/model-regression-detection-system)**

`TypeScript` `RAG Pipeline` `LLM Integration`

**[→ View Repo](https://github.com/darshild078/ytvideo-chatbot)**
